# Software Factory

A code-defined, graph-oriented software factory. It schedules deterministic and Pi-backed workflow nodes across isolated Git worktrees.

## Status

The MVP is under construction. Architecture: [`docs/superpowers/specs/2026-08-05-software-factory-design.md`](docs/superpowers/specs/2026-08-05-software-factory-design.md).

## Development

```bash
npm install
npm run test:run
npm run build
```

Copy `.env.example` to `.env` when running the local services.
